## 📖 Sobre o Projeto

É um website educacional criado pelo squad **Phoenix Dev's**, desenvolvido para documentar de forma clara, moderna e profissional os **8 principais tipos de testes de software**. Cada seção contém:

- 📚 Explicação teórica detalhada
- 🛠️ Quando usar e ferramentas recomendadas
- 💻 Exemplos de código reais
- 🎥 Vídeo demonstrativo (link externo)

O design foi inspirado em uma identidade visual **dark navy + magenta neon**, com efeitos de glassmorphism, animações suaves e tipografia premium (**Plus Jakarta Sans**).

## ✨ Funcionalidades

- 🎨 **Design Moderno** — Interface dark com detalhes em magenta neon
- 📱 **Totalmente Responsivo** — Adaptado para desktop, tablet e mobile
- 🪟 **Glassmorphism** — Efeito de vidro fosco nos cards
- 🌊 **Animações de Scroll** — Cards aparecem suavemente conforme você rola a página
- 💫 **Micro-interações** — Hover elegante em botões e cards
- 💻 **Blocos de Código** — Exemplos reais com syntax highlighting manual
- 🎬 **Integração com YouTube** — Links diretos para vídeos demonstrativos
- 🧭 **Navegação Suave** — Smooth scroll entre as seções
